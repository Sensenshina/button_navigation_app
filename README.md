ความแตกต่างของปุ่มทั้ง 3 ประเภท
1) ElevatedButton (ปุ่มแบบนูน)
รูปลักษณ์ (Appearance): เป็นปุ่มที่มีสีพื้นหลัง (Fill Color) เด่นชัด และมี เงา (Elevation/Shadow) ด้านล่าง ทำให้ปุ่มดูลอยขึ้นมาจากพื้นผิวของหน้าจอ
กรณีการใช้งานที่เหมาะสม: * ใช้สำหรับ การกระทำหลัก (Primary Action) ที่เราต้องการให้ผู้ใช้มองเห็นเป็นอันดับแรกและกดมากที่สุดในหน้านั้น
เช่น ปุ่ม "เข้าสู่ระบบ (Login)", "ชำระเงิน (Pay Now)", "บันทึกข้อมูล (Save)"
2) OutlinedButton (ปุ่มแบบมีเส้นขอบ)
รูปลักษณ์ (Appearance): เป็นปุ่มที่ไม่มีสีพื้นหลัง (โปร่งใส) แต่จะมี เส้นขอบ (Border) ล้อมรอบข้อความอย่างชัดเจน และไม่มีเงา
กรณีการใช้งานที่เหมาะสม: * ใช้สำหรับ การกระทำรอง (Secondary Action) ที่มีความสำคัญน้อยกว่าปุ่มหลัก แต่ยังต้องการให้สังเกตเห็นได้ง่าย
มักใช้คู่กับ ElevatedButton เพื่อเป็นทางเลือกเสริม
เช่น ปุ่ม "ยกเลิก (Cancel)" (วางคู่กับปุ่มบันทึก), ปุ่ม "ดูประวัติย้อนหลัง (View History)"
3) TextButton (ปุ่มแบบข้อความ)
รูปลักษณ์ (Appearance): มีเฉพาะข้อความ (หรือไอคอน) ไม่มีสีพื้นหลัง และไม่มีเส้นขอบใด ๆ ดูเรียบเนียนไปกับพื้นผิวของแอป (จะแสดงพื้นหลังจาง ๆ เฉพาะตอนที่เอานิ้วไปกด )

ขั้นตอนการทำงานของ Navigator.push ในการเปลี่ยนหน้าจอ
1. เรียกใช้งานฟังก์ชัน: เมื่อผู้ใช้กดปุ่ม เราจะเรียกใช้คำสั่ง Navigator.push(context, route)
2. ระบุปลายทาง (Route): เราต้องสร้าง Route (ส่วนใหญ่นิยมใช้ MaterialPageRoute) เพื่อระบุว่าต้องการจะเปิดหน้าจอ (Widget) ไหน และควบคุม Animation ตอนเปลี่ยนหน้า
3. นำหน้าใหม่วางทับ (Push): Flutter จะนำหน้าจอใหม่นั้น ไปวางทับไว้บนสุดของ Stack ของระบบนำทาง
4. แสดงผลและเริ่มทำงาน: หน้าจอใหม่ปรากฏขึ้นมาบนสุดของหน้าจอผู้ใช้, หน้าจอเดิม (หน้าก่อนหน้า) จะถูกบังไว้ด้านล่าง แต่ยังไม่ถูกทำลาย (ยังคงอยู่ใน Stack และรักษาสถานะเดิมไว้)
5. การย้อนกลับ (แถม): เมื่อผู้ใช้กดปุ่มย้อนกลับ หรือคำสั่ง Navigator.pop(context) หน้าจอที่อยู่ด้านบนสุดจะถูกดึงออก (Pop) และทำลายทิ้งไป ทำให้หน้าจอเดิมที่อยู่ด้านล่างกลับมาแสดงผลเหมือนเดิมครับ
